# WorkHack: ядро контекста (читается в начале каждой сессии)

## Проект
- Русскоязычный проект про поиск работы. Telegram **@hackforworks** («WorkHack | Поиск работы»), сайт workhack.online, маскот: жёлтая утка. Аудитория: junior и люди, меняющие сферу.
- WorkHack ≠ gobl1nlog (другой проект, не смешивать).
- Площадки: Telegram (основная), Threads, Instagram, TikTok, YouTube Shorts. X пока не ведём. VK, Дзен: не делаем.
- Подписчиков меньше 10 суммарно: растим с нуля.
- Заявки идут на контакт менеджера (не бот). Платные продукты в рекламе не обещать («Скоро», Offer Sprint = гипотеза).

## Правила контента (нарушать нельзя)
- В КАЖДОМ посте картинка с жёлтой уткой. Нет картинки = пост не публикуется.
- Без «кринжа»: никаких выдуманных шуток и мем-текстов. Юмор только утверждённый человеком.
- Факт без источника не публикуется: открыть ПЕРВОИСТОЧНИК, сверить цифры, новость не старше 7 дней. Не выдумывать работодателей, вакансии, кейсы, отзывы, опыт. Не обещать оффер или доход. Учебные примеры помечать.
- Структура поста: первая строка ⚡️ + цепкий заголовок; 3–5 коротких абзацев с цифрами и источником; ироничный вывод; подпись @hackforworks; 600–1000 знаков (подпись под фото не больше 1024). Один CTA максимум.
- Чужие видео как картинку не использовать (права, риск охватов). Чужое только как повод для темы.
- Голос только живой голос пользователя. Клонировать голоса без отдельного согласия нельзя.
- Клиентские данные, переписки и голос новым сервисам (Gemini, Grok, Higgsfield, ElevenLabs) без согласия не передавать.
- Нельзя: покупать и платить, удалять аккаунты, писать людям от имени человека, заходить в личный Telegram, вводить пароли и коды, обходить CAPTCHA.
- Первая неделя: посты сначала в `queue/<дата>/`, у человека есть вето. Если вето нет до слота, публиковать.

## Картинки утки
- Генерация в ChatGPT, по 3 варианта на пост. Claude растр не делает, он выбирает лучший вариант: утка одна, без текста и букв, без лишних конечностей, читается сюжет.
- Стиль: глянцевая мягкая 3D-мультяшная иллюстрация, жёлтая утка в чёрных солнцезащитных очках с чёрным кейсом, светлый офис с панорамными окнами, кадр 3:2, малые роботы для ИИ-тем.
- Файлы картинок кладём в бакет: `wh put <файл> assets/duck-ГГГГ-ММ-ДД-<тема>.png`.

## Ежедневный конвейер (3 поста в сутки, минимум 1 новостной)
Слоты ~09:00, 15:00, 21:00 МСК. Тема и источник → 3 текста + сюжет картинки → 3 варианта картинок → выбор лучшей и контроль по правилам выше → публикация → запись в журнал. Воскресенье: недельная аналитика. Полный runbook: `wh get context/runbook-full.md`.

## Как работаем с общей памятью
- Задача дня называется `daily-ГГГГММДД`. Перед работой `wh claim daily-…`, в конце `wh done … --task daily-…`.
- Все действия пишутся в журнал бакета командой `wh`. Событие нельзя править, только добавлять новое.
- Каждое сообщение и ответ ИИ автоматически попадают в журнал `messages/` (его видит партнёр). Последние 6 сообщений показываются при старте. Режим: `wh config log_messages full|prompts|off`.
- Секреты нигде не хранить и не писать.
- Время в журнале UTC (московское = UTC+3).
