# Общая память WorkHack

Контекст и журнал действий лежат в общем бакете R2. Команда `wh` работает с ним. Хуки плагина уже прочитали контекст при старте сессии (он выше в разговоре) и не дадут закончить без записи итога.

## Порядок работы
1. **Старт.** Контекст уже загружен хуком. Нет блока «WorkHack: общий контекст» или есть «КОНТЕКСТА НЕТ»: выполни `wh start` и скажи пользователю, если не получилось. Без контекста не работай.
2. **Задача дня.** Перед ней: `wh claim <задача>` (например `daily-20261109`). Код 0 = твоя. Код 1 «занято» или 2 «уже закрыта» = не делай, сообщи пользователю.
3. **По ходу.** После каждого результата (пост опубликован, картинка выбрана, сценарий готов, найдена проблема): `wh note "что и где лежит"`.
4. **Файлы.** Картинки, видео, пакеты: `wh put <файл> assets/…` или `ready/…`, в событии указывай ключ: `wh note "..." --file assets/duck-2026-11-09.png`.
5. **Финиш.** `wh done "что сделано + ключи файлов" --task <задача>`. Не успел: `wh handoff "причина и что осталось"`. Сломалось: `wh fail "что и почему"`.
6. **Нужен другой файл контекста.** Список в блоке «Другие файлы контекста». Читать: `wh get context/<имя>`.

## Запреты
- Секреты (токены, пароли, ключи, коды 2FA) не писать никуда: ни в события, ни в файлы, ни в чат.
- Не править и не удалять чужие события. Они неизменяемые: исправление = новое событие.
- Не выдумывать состояние. Нет данных в контексте: так и скажи.

## Если нет связи
`wh` сам кладёт события в локальную очередь и отправит их при следующем запуске. Скажи пользователю, что бакет был недоступен.
