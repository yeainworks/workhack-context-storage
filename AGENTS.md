# Правила для агентов в этом репозитории

- Установка и настройка: прочитай `INSTALL.md` и выполни по шагам. Секреты в чат не просить и не повторять.
- Ничего не коммить и не пушь без прямой просьбы человека.
- Менять код `bin/wh.py` можно только вместе с тестами. Запуск: `python3 -m unittest discover -s tests`. Перед правкой прочти `tests/test_wh.py`.
- Зависимости не добавлять: только стандартная библиотека Python 3.9+.
- Секреты никогда не писать в репозиторий, события и логи.
- Работа по самому проекту WorkHack идёт в его папке; правила общей памяти (`wh start` → `wh claim` → `wh done`) добавляются туда командой `wh init-project <папка>`.
