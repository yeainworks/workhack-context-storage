# Автозапуск и журнал каждого сообщения

Что происходит само, без твоих команд, и как это проверить и починить.

## 1. Что запускается само

### Claude Code (основной путь, всё автоматически)
Плагин `workhack-context` вешает пять хуков. Они работают только в папках с файлом `.wh-project` (его создаёт `wh init-project`), в остальных проектах Claude Code ведёт себя как обычно.

| Когда | Что делает хук | Куда пишет |
|---|---|---|
| Старт, продолжение или очистка сессии (`SessionStart`) | читает из бакета `core.md`, состояние, последние 15 событий, последние 6 сообщений, занятые задачи и кладёт это в начало сессии | ничего не пишет |
| Каждое твоё сообщение (`UserPromptSubmit`) | пишет текст сообщения в журнал, секреты вырезает | `messages/ДАТА/…-user-….json` |
| Конец ответа ИИ (`Stop`) | пишет последний ответ ИИ в журнал; если итог не записан, один раз просит `wh done` | `messages/…-assistant-….json` |
| Перед сжатием контекста (`PreCompact`) | пишет чекпоинт со ссылкой на транскрипт | `events/…-checkpoint-….json` |
| Закрытие сессии (`SessionEnd`) | если итога не было, пишет «закончилась без итога» | `events/…-session-end-….json` |

После сжатия контекста (`compact`) `SessionStart` срабатывает снова и возвращает контекст в сессию: именно в этот момент информация чаще всего теряется.

### Codex (почти автоматически, через обёртку)
Хуков у Codex нет. Запускай его через `bin/wh-codex`: он читает контекст из бакета, подставляет его в первый запрос Codex, а после выхода пишет в журнал событие `session-end`.

```bash
/путь/к/workhack-context-storage/bin/wh-codex "задача на сегодня"
```
Чтобы запускалось короче, добавь в `~/.zshrc`:
```bash
alias codex-wh='/путь/к/workhack-context-storage/bin/wh-codex'
```
Принудительной записи итога у Codex нет. Журнал каждого сообщения для него тоже не ведётся автоматически: записывай итог командой `wh done` и промежуточные шаги `wh note`.

### ChatGPT в чате
Автозапуска нет, только ручной мост: `wh pack` перед работой, `wh ingest` после (см. `docs/USAGE.md`, раздел 5).

## 2. Журнал каждого сообщения
Что хранится: `messages/ГГГГ-ММ-ДД/ЧЧММСС-имя-роль-xxxxxx.json` с полями `ts` (UTC), `who`, `role` (`user` или `assistant`), `session`, `text`. Один файл = одно сообщение, файлы не перезаписываются.

Как это попадает в контекст: при старте любой сессии `wh start` показывает 6 последних сообщений из журнала (за вчера и сегодня), так что партнёр или другая нейронка видит, на чём остановились. Старые сообщения читай вручную:
```bash
wh ls messages/2026-11-12/          # список за день
wh get messages/2026-11-12/ИМЯ.json # одно сообщение
```

Ограничения, о которых нужно знать:
- **Видит партнёр.** Бакет общий. Личные разговоры в сессиях WorkHack не веди, или выключи журнал.
- **Секреты вырезаются** (токены, пароли, длинные ключи), но надеяться только на это нельзя: не вставляй секреты в чат с ИИ.
- **Длинные сообщения обрезаются** до 4000 символов.
- **Ответы ИИ пишутся целиком только текстом.** Вызовы инструментов и вывод команд в журнал не попадают.
- Нет связи: сообщения копятся в `~/.workhack/outbox` и отправляются при следующем `wh start` или `wh flush`.

Режимы (меняются командой, действуют сразу):
```bash
wh config log_messages full      # по умолчанию: твои сообщения и ответы ИИ
wh config log_messages prompts   # только твои сообщения
wh config log_messages off       # журнал сообщений выключен (события и итоги остаются)
```
Временно на один запуск: `WH_LOG_MESSAGES=off claude`.

## 3. Проверка автозапуска (2 минуты)
1. `wh doctor`: шесть ✓.
2. `claude plugin list`: есть `workhack-context`, статус `enabled`.
3. Открой Claude Code в папке проекта WorkHack. Задай любой вопрос. В начале сессии (ответ ИИ может сослаться на него) должен быть блок «WorkHack: общий контекст».
4. `wh ls messages/$(date -u +%Y-%m-%d)/`: появились два файла (твой вопрос и ответ ИИ).
5. Закрой сессию без `wh done`: хук один раз попросит итог. После `wh done` сессия закроется.

## 4. Если автозапуск не работает
| Что видишь | Причина | Что делать |
|---|---|---|
| Блока контекста нет вообще | сессия открыта не в папке проекта | открой Claude Code в `…/Projects/workhack` или подпапке. Проверь, что там есть `.wh-project` |
| Блока нет, папка верная | плагин не установлен или выключен | `claude plugin list`. Нет: `claude plugin marketplace add <папка репозитория>` и `claude plugin install workhack-context@workhack-context-storage` |
| Блок есть, но «КОНТЕКСТА НЕТ» | нет сети или неверные ключи | `wh doctor`. Ключи неверные: `wh setup` |
| Контекст старый после обновления репозитория | плагин ставится копией | обнови: `claude plugin marketplace update workhack-context-storage`, затем `claude plugin update workhack-context@workhack-context-storage`, потом перезапусти Claude Code |
| Сообщения не пишутся | режим `off` или `prompts` | `wh config log_messages full` |
| Хуки ругаются на `wh` | нет Python | `python3 --version` (нужен 3.9+) |

## 5. Если ты ИИ-агент
Скилл для агентов: `skills/workhack-autostart/SKILL.md`. Коротко: проверь, что блок «WorkHack: общий контекст» есть в начале сессии; если нет, выполни `wh start` сам, прочитай, скажи человеку о проблеме. В конце запиши итог `wh done`.
