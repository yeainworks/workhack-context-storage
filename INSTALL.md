# INSTALL.md: инструкция для ИИ-агента

Ты агент с доступом к терминалу (Claude Code, Codex). Выполни установку по шагам. Не пропускай проверки и не придумывай значения.

## Жёсткие правила
- **Секреты в чат не просить и не повторять.** Account ID и имя бакета не секреты, их можно спрашивать. Access Key ID и Secret Access Key вводит человек сам в своём терминале командой `wh setup` (ввод секрета скрыт).
- Если человек всё же прислал ключ в чат: запиши его через переменные окружения, не печатая (`WH_SETUP_ACCESS_KEY_ID=… WH_SETUP_SECRET_ACCESS_KEY=… bash install.sh`), не повторяй в ответах, не сохраняй в файлы репозитория и скажи, что токен после этого лучше пересоздать.
- Ничего не коммить и не пушь в git.
- Не меняй глобальные настройки машины, кроме того, что делает `install.sh`.

## Шаги
1. **Определи окружение.** `uname -s`. macOS/Linux: используй `install.sh`. Windows: `install.ps1`. Нет терминала (чат ChatGPT без оболочки): установка невозможна, объясни человеку `docs/USAGE.md`, раздел 5, и остановись.
2. **Узнай у человека** (одним сообщением): путь к папке проекта WorkHack (по умолчанию `/Users/vladimirg.sergeev/ALL WORKS/Projects/workhack`) и его имя для журнала латиницей (например `vlad`). Больше ничего не спрашивай.
3. **Запусти установку:**
   ```bash
   bash install.sh --project "<папка проекта>"
   ```
4. **Код выхода 10 (`NEED_SETUP`):** данных R2 нет. Скажи человеку дословно: «Открой терминал и выполни `wh setup` (или `<путь к репозиторию>/bin/wh setup`). Понадобятся Account ID, имя бакета, Access Key ID, Secret Access Key. Секрет вставляется скрыто. Скажи мне, когда закончишь». Дождись ответа и повтори шаг 3.
5. **Код выхода 11 (doctor не прошёл):** найди строку с ✗ в выводе и действуй по таблице ниже. После исправления повтори шаг 3.
6. **Код выхода 0:** проверь вручную:
   ```bash
   wh doctor      # пять ✓ и «всё работает»
   wh start       # печатает контекст из core.md, события, claim
   wh note "установка завершена на $(hostname)"
   ```
7. **Плагин Claude Code.** `install.sh` ставит его сам, если есть `claude`. Проверка: `claude plugin list` содержит `workhack-context`. Если нет:
   ```bash
   claude plugin marketplace add "<путь к этому репозиторию>"
   claude plugin install workhack-context@workhack-context-storage
   ```
   Плагин даёт хуки старта/финиша и скилл `workhack`. Хуки срабатывают только в папках с файлом `.wh-project` (его создал `--project`). Для проверки открой новую сессию Claude Code в папке проекта: в начале должен быть блок «WorkHack: общий контекст».
8. **Для Codex:** отдельной установки нет. `--project` положил правила в `AGENTS.md` проекта. Проверь, что файл содержит блок между `<!-- wh:begin -->` и `<!-- wh:end -->`.
9. **Отчёт человеку** (коротко): что установлено, результат `wh doctor`, нужно ли добавить `~/.local/bin` в PATH, что делать дальше (`docs/USAGE.md`, раздел 3).

## Если не работает
| Вывод | Причина | Действие |
|---|---|---|
| `NEED_SETUP` (код 10) | нет `~/.workhack/config.json` и `credentials` | шаг 4 |
| `✗ соединение: ... Name or service not known` | нет интернета / неверный Account ID | проверить сеть; Account ID из Cloudflare → R2 |
| `HTTP 403` | токен без прав на бакет или опечатка в ключе | пересоздать токен с `Object Read & Write` на этот бакет, `wh setup` заново |
| `HTTP 404 NoSuchBucket` | неверное имя бакета | `wh setup` заново |
| `✗ If-None-Match (атомарный claim)` | R2 не принял условную запись | сообщить человеку: claim ненадёжен, остальное работает |
| `python3: command not found` | нет Python | macOS: `xcode-select --install`; иначе `brew install python` |
| `wh: command not found` | `~/.local/bin` нет в PATH | вызывай `<репозиторий>/bin/wh` или добавь строку из вывода install.sh в `~/.zshrc` |
| `claude plugin ...` ошибка | старая версия CLI | обновить Claude Code; пока работает запасной путь: `AGENTS.md` + ручные `wh start` / `wh done` |
